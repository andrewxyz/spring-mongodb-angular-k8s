# spring-mongodb-angular-k8s

A small **Tutorials** CRUD app, built as a learning project for Kubernetes: an Angular frontend, a Spring Boot REST API and a MongoDB database, all running in a local [kind](https://kind.sigs.k8s.io/) cluster behind a Traefik Ingress.

You can add, search, edit, publish and delete tutorials in the browser. The interesting part is how the three pieces are packaged and deployed: every Kubernetes file lives in [k8s/](k8s/) and is commented for beginners.

## What's inside

| Folder | What it is | Details |
|---|---|---|

## Architecture at a glance

```
Browser ── http://mylocal.localhost ──► Traefik (Ingress controller)
                                            │
                       ┌── /api ────────────┴──────────── / ───┐
                       ▼                                       ▼
              backend-service                          frontend-service
              2 × Spring Boot pods                     2 × nginx pods (Angular)
                       │
                       ▼
              mongodb (StatefulSet, 1 pod) ──► PersistentVolumeClaim (1Gi)
```

The browser loads the page and calls the API on the same address, so there's no CORS setup and no hardcoded backend URL. For the full diagram, request flows and the reasons behind each design choice, see [k8s/README.md](k8s/README.md#architecture).

## Prerequisites

- JDK 25 and Node.js 20 (for running locally)
- Docker
- [kind](https://kind.sigs.k8s.io/), `kubectl` and [Helm](https://helm.sh/) (for the Kubernetes path)

## Quick start

### Option 1: run on your machine

```bash
# MongoDB
docker run -d --name belajar-mongo -p 27017:27017 mongo:7

# Backend (port 8080), in one terminal
cd spring-boot-data-mongodb
./mvnw spring-boot:run

# Frontend (port 8081), in another terminal
cd angular-crud
npm install
npm start
```

Open **http://localhost:8081**. More detail: [backend](spring-boot-data-mongodb/README.md#run-locally) and [frontend](angular-crud/README.md#run-locally).

### Option 2: run on Kubernetes (kind)

From the repo root:

```bash
kind create cluster --name demo-cluster --config k8s/kind-config.yaml

helm repo add traefik https://traefik.github.io/charts
helm install traefik traefik/traefik -n traefik --create-namespace -f k8s/traefik-values.yaml

docker build -t belajar-backend:1.0.0  spring-boot-data-mongodb
docker build -t belajar-frontend:1.0.0 angular-crud
kind load docker-image belajar-backend:1.0.0 belajar-frontend:1.0.0 --name demo-cluster

kubectl apply -k k8s/
kubectl get pods -n demo-namespace -w        # wait until everything is Ready
```

Open **http://mylocal.localhost**. More detail, everyday commands, experiments to try and clean-up steps: [k8s/README.md](k8s/README.md).

## Kubernetes objects used

Namespace, Pod, Deployment (2 replicas each for backend and frontend), StatefulSet (MongoDB), Service (ClusterIP and headless), Ingress, ConfigMap, Secret, PersistentVolumeClaim and liveness/readiness/startup probes.

## Known limitations

This is a learning setup, not a production one (see [k8s/docs/production.md](k8s/docs/production.md) for how production differs):

- MongoDB runs as a single replica, and so does Traefik.
- No HTTPS: port 443 is open but there's no certificate.
- The MongoDB password in [k8s/mongodb/secret.yaml](k8s/mongodb/secret.yaml) is a throwaway value stored in plain text. Don't reuse it anywhere real.
- The API has no authentication, and `DELETE /api/tutorials` removes every tutorial.
- The Angular test files were generated by the CLI and haven't been fixed, so `npm test` is expected to fail.
